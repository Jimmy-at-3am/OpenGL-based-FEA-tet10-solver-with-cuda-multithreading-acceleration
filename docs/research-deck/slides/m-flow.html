The system manual's linear-solve flowchart on one slide. Steps 1 to 6 build K and F. The cost model (direct_solve::estimate) orders the matrix with AMD, walks the elimination tree to count non-zeros per column of L and estimates flops = sum of squared column counts; with directWhenCheap on (the app default) cheap problems skip the iterative solvers. Otherwise the GPU PCG runs when the GPU is on; any GPU failure hands over to CPU CG, and a CG failure hands over to the CPU LDL-transpose factorisation. Every path ends with u, then stress and reactions are recovered and the model returns to display units.
