Geometry input and the Bambu Studio bridge

Geometry input

loadPartAsTriangles(path)

Job read one part file into a triangle soup, in the file's own units

In → Out .stl / .3mf / .step → positions + indices

How reader picked by file extension · STL: binary or ASCII, duplicate vertices welded · 3MF: build items + components; normal parts kept, modifiers ignored, negative parts rejected · STEP: OpenCASCADE, exact B-rep kept for nearest-point queries [1, 2, 3]

openPackageArchive(path)

Job open .3mf zip packages, Unicode paths included · Out miniz reader

normalizeRawGeometry(mesh)

Job clean every loaded mesh before use

How weld vertices → optional decimation (meshoptimizer) [4] → recompute normals → keep the real size in mm → centre and scale into the 3-unit render space

writeSlicerInputStl(triangles)

In → Out triangles → temporary binary STL in mm, for Bambu Studio

rebuildSphereAsIcosphere(mesh)

Job detect badly tessellated spheres and rebuild them (legacy path)

Bambu Studio bridge

locateSlicer()

How saved bambuStudioExe in %LOCALAPPDATA%\PolyFEA\settings.json → Windows installed-programs list → Locate Bambu Studio… (remembered)

runHeadlessSlice(request, cancelFlag)

In → Out project or temp STL → sliced package .3mf + result.json

How bambu-studio.exe --slice 1 --export-3mf; STL adds --load-settings, --load-filaments, --arrange 1, --orient 0 · read return_code / error_string · Cancel ends the process

Why Bambu's own code is AGPL and needs Boost, TBB, CGAL and OpenVDB; the installed program slices exactly as the printer will [5]

listPrinterPresets(printer)

How read Bambu's BBL profiles → keep "instantiation": "true" → filter process and filament by printer

unpackSlicedPackage(path)

In → Out .3mf → plain model, placement, settings, G-code, print summary

How plain-language error for several parts, wrong plate, several filaments, negative parts

mapCoordinateFrames(x)

Job the only converter between frames; every number comes from the package

Method names are descriptive, not the identifiers in the source. Real modules: IGeometryLoader, GeometryLoaderDispatch, STLLoader, ThreeMFLoader, StepLoader + BRepHandle, ZipReader, StlWriter, GeometryUtils, FEAModel::processRawGeometry; BambuSlicer (locate, slice), BambuPresets, SlicedPackage::load, PartPlacement. s = modelToMM, the largest bounding-box side divided by 3. The solver converts back to metres and works in SI units on the real part size.
