The system in one paragraph

PolyFEA is one C++17 desktop program, about 46,000 lines. It opens a part, asks the installed Bambu Studio to slice it, rebuilds each printed layer as a 2D shape, stacks those shapes into a 3D mesh of tetrahedra, and ties neighbouring layers with weaker springs. The user picks loads on the clean CAD model, and PolyFEA moves them onto the printed mesh. The solver builds one equation, Ku = F, solves it on the GPU or CPU, computes stress, and can delete overloaded elements to simulate cracking. OpenGL draws everything, and a headless runner drives the same functions from JSON files for testing.

From the system manual's one-paragraph summary. The headless runner is ScenarioRunner; the executable is FEAPreProcessor.exe.
