Appendix 3 · Pause and Hard Stop

Problem

long fracture runs could not be stopped, and closing the app waited for them; a direct factorisation cannot be interrupted from inside a thread

Thinking

  • extra cancel checks cannot stop an opaque library call
  • killing a thread would corrupt the app's memory
  • so the solve runs in a separate process that can be killed safely
  • Pause must save a real, checked checkpoint, never a frozen process

Solution

  • a worker process: the app starts a second copy of itself and sends it the job; live status comes back through shared memory
  • versioned .pfea run files, written and verified before publishing
  • Pause / Resume / Keep results, plus a close-during-run dialog: Pause, Save & Exit · Hard Stop & Exit · Back

Result · Hard Stop, measured

Multithreaded CG

189 ms

Direct LDLᵀ

111 ms

GPU PCG

232 ms

Hard Stop ends the process at once and throws away unfinished work; the part and earlier saved runs are not touched

Result · the test really checks it

a mutation test switched Pause off on purpose, and the lifecycle test failed

How Pause differs

the worker stops at a safe point and writes a checkpoint (.pfea under %LOCALAPPDATA%\PolyFEA\checkpoints); the run can resume later, even after closing the app
