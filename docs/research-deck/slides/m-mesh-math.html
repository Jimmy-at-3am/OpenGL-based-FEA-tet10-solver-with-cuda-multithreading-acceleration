The maths behind the mesh

Weld ties between slabs, derived

1 · Hooke's law across one slab of thickness t [15]

2 · The tie is a spring α times stiffer than the slab it bridges

3 · Slab and tie act in series, so with α = 100 a layer stack stretches only about 1 % more

4 · The tie gap joins a top node to a barycentric point inside the triangle below [12]

5 · Differentiate the spring energy twice: the entries added to K

Ez stiffness across layers · A, Atie area one tie carries · t slab thickness · δ stretch · α = tieAlpha · wᵢ barycentric weights · u nodal displacements · Ut tie energy

Element stiffness [16, 17]

Takes node positions and the material matrix D · Gives the element block Ke

Implies Tet4 strain is constant inside each element, so it is too stiff in bending; the 4-point rule is exact for Tet10's degree-2 integrand, so Tet10 bends accurately

Mesh quality [14, 18, 19]

Takes each element's corner edges e₁, e₂, e₃ and volume V · Gives one score per metric

Implies a regular tet scores q = SJ = ρ = 1 and S = 0; SJ ≤ 0 is an inverted element (FAIL); a dihedral angle under 10° is a sliver; the mesh passes when dH < 1 % of the box diagonal

Weld ties: the code adds K_top,top += k_t, K_top,bi -= k_t w_i, K_bi,bj += k_t w_i w_j for every tie, with k_t = tieAlpha · E_z · A_tie / t. The derivation shows where those three updates come from: Hooke's law gives the slab's own axial stiffness, the tie is defined as alpha times that, the series rule shows why alpha = 100 only adds about 1 % stretch, and the Hessian of the tie energy gives the matrix entries. Mesh quality also checks the 95th-percentile normal deviation (< 15°).
