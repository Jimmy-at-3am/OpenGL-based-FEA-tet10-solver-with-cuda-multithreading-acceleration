Open a part, then mesh it

Step 1 · Open a part (Model tab)

  1. Click Open part… and choose a Bambu Studio project (.3mf), or an STL / STEP file with a printer, process and filament preset, then Slice with these presets.
  2. Slicing runs in the background for a few seconds; Cancel stops it. If Bambu Studio is missing, use Locate Bambu Studio…
  3. Read the print summary. The material card follows the filament (PLA, PETG, TPU); for any other filament, pick a card.
  4. Print settings change only in Bambu Studio.

Step 2 · Make the mesh (Mesh tab)

  1. Open the Mesh tab.
  2. Optional: set Maximum slabs. A slab is a group of printed layers; more slabs give finer layers and a slower solve.
  3. Click Generate volume mesh. The progress panel shows the work, and the title bar then says Mesh ready.
  4. Loads chosen earlier move onto the new mesh automatically, and again after every re-mesh.
