Set up the load, then run

Step 3 · Loads and supports (Solve tab)

  1. Add conditions: + Push / pull, + Bend, + Twist, + Hold / support, + Pressure, + Gravity. All of them add up to one load case.
  2. Pick Point or Surface (Face or Plane), click Choose where it acts, click the yellow highlight; Shift+click adds faces; Done picking.
  3. A plane goes on a clicked face; drag its 3 arrows and 3 rings (Ctrl snaps 1 mm, 15°) and keep only the pieces you need.
  4. Type the size in mm, N or N mm, then read the receipt: total force, moment, held directions, warnings.

Step 4 · Run the simulation

  1. Settings: Multithreading uses every CPU core, GPU acceleration (CUDA) uses the NVIDIA GPU, FDM anisotropy keeps separate in-layer and between-layer strengths.
  2. Run Stress + deformation first, Estimate breaking load for a safe load, or Explore fracture at these loads to see where it breaks.
  3. While it runs, the progress panel shows stage, device and threads. Pause saves a checkpoint; Hard Stop ends the run at once.
