Appendix 1 · Material model

buildMaterialMatrix(card)

Job give the 6 × 6 material matrix D

How isotropic plastic uses E and ν; the printed-part material uses Ep, Ez, νp, νpz, Gpz with the weak axis set to the build direction

Cards .mat files are plain key = value text in SI units; the filament picks the card (PLA → pla.mat, PETG → petg.mat, TPU → tpu_rubber.mat)
