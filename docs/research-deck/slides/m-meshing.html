Meshing the printed layers

meshPrintedSlabs(layerShapes)

Job build the 3D finite element mesh from the layer shapes · In → Out layer sections → Tet4 volume mesh + layer stack (slab planes, ties)

How it works

1

Group layers into slabs; default maxSlabs = 128

2

Triangulate each slab's shape, constrained Delaunay [10]: ring edges ≤ 5 × median line width, interior lattice points so no thin slivers

3

Extrude every triangle into a prism one slab thick

4

Split every prism into 3 tetrahedra by the global-index rule, so neighbouring prisms cut their shared faces the same way [11]

5

Tie each slab to the one below: every top node is tied to a point inside a triangle below by barycentric weights [12] (tieAlpha = 100). The layer bond becomes a separate, weaker link

6

Report checks: areaErrMaxPct, sumThickOverAreaPerMM

Element stiffness each tetrahedron becomes a Tet4 block; Tet10 adds a node at every edge midpoint, ½(xᵢ + xⱼ)

Weld ties each tie is a spring of stiffness kₜ between slabs, added straight into K

Mesh quality the TetGen path for CAD surfaces is graded by shape metrics and Hausdorff distance [13, 14]
