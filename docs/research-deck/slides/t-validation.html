How every test runs scenario.json → the headless runner (same functions as the buttons) → report + screenshots → asserts → exit code · 30 of 30 scenarios pass on the 4 Oct 2026 build

Cantilever: README benchmark from the first commit (7 May 2026); five TetGen meshes vary quality and maximum element volume independently; run 2 is the densest yet has 2.6 % error. Shaft: the anisotropic fracture acceptance test (scenarios shaft_break_standing, shaft_break_lying, shaft_break_standing_iso; values from the 4 October build). Seven checks ran before any value was frozen into a test: same-force comparison, isotropic control, hand-calculated force anchors, force balance, mesh-size sweep, tie-stiffness sweep, and failure mode and location on screenshots.
