Turning picks into solver input

findOutsideSurface(slab)

Job find the surface triangles that touch outside air, so a load never lands inside an infill gap

How part's XY box + 1 mm, minus the slab's shape → empty regions [21]; a region is outside air if it reaches the surroundings, or the air below or above the stack through truly empty layers; sealed infill gaps never count

transferPicksToMesh(selection)

Owner each outside triangle belongs to the nearest plain face facing within 90°; ties go to the lower face number

Face load every outside triangle owned by the face

Line load the plane cuts the owned triangles; force is spread by segment length

Touch line step every half line width, take the nearest node, share by length

Point nearest point on the owned triangles [12]

Nothing to load a plain message: “This face is thinner than one printed line”

compileLoadCase(conditions, mesh)

In → Out load case + mesh → force vector, moment, fixed DOFs, warnings, error

Support fixes X, Y, Z on its nodes. Support check: per connected piece, the 6 rigid motions are tested against the fixed directions; one left free blocks the run

After the solve the receipt adds reactions and the equilibrium residual

assessCapability(feature)

one registry answers Exact, Approximate or Unsupported for every feature; the UI and the tests ask the same registry; unsupported features stay visible but cannot run

The physics problem balance at every point, then the weak form [16]

Supports by penalty a very stiff spring; K stays symmetric positive-definite for CG [22]

σ stress · b body force · u, v real and virtual displacement · C material tensor · t̄ applied traction

Real names: OutsideSurface; LoadTransfer with owners(), planePieces(), transfer(); LoadSetup (load_setup::compile) returning Compiled {forceN, momentNm, fixedDofs, warnings, error}; LoadPhysics with assess() and assessPreset(). Feature kinds in the registry: PointForce, PatchResultant, Pressure, BearingLoad, RemoteResultant, BodyAcceleration, FixedConstraint, PrescribedDisplacement, Contact. The physics problem and the penalty supports are the maths behind these modules.
