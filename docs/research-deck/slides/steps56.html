Read the results, then save

Step 5 · Read the results

  1. The banner names the view: von Mises stress (MPa), deformation, failure type, crack order, stress at break, or the fracture summary.
  2. Switch with Stress / Deformation; fracture runs add Deform, Mode, Crack order and Break stress. Broken elements: Hidden, Ghost or Colored.
  3. The legend top is the 99th percentile; “+” and PEAK mark a clipped scale. The solved reactions should equal your load.

Step 6 · Save and reopen

  1. Pause writes a .pfea file under %LOCALAPPDATA%\PolyFEA\checkpoints.
  2. Open saved run (.pfea) reopens a paused or finished run without Bambu Studio; the sliced part is stored in the file.
  3. Resume run continues a paused run from where it stopped.
  4. Keep results / End run ends a paused run and keeps its results.
