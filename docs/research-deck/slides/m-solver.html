From the sliced mesh to the FEA solver

How the printed mesh becomes Ku = F

1 · Real size geometry scaled to metres; the solve runs in SI units on the true part size

2 · Elements every slab tetrahedron becomes a Tet4 block (Tet10 after mid-edge nodes), each element remembers its slab; the weak material axis is the build axis z

3 · Assembly Ae maps element unknowns to global ones (node × 3 + direction); each element writes its own block of triplets, then shared nodes are summed [16]

4 · Layers and supports weld ties add their springs between slabs; supports add the penalty α to the diagonal

5 · Recover element stress, then a printed-part failure ratio with three checks [31, 32]

PLA limits: layers pulled apart 22.8 MPa · layers sliding 18 MPa · inside a layer 50 MPa [33]. r > 1 fails the element; the largest term names the mode. No compression or buckling check
