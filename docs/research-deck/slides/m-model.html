On opening a finished run, the default view is stress when it exists, otherwise deformation, with broken elements in magenta.

FEAModel (+ FEAData) is the one object every stage reads and writes. Field groups (magenta) with example fields: surface for drawing (vertices, indices, render buffers); real size (physicalMinMM, physicalMaxMM, modelToMM); volume mesh (originalVolumetricPositions, tetrahedra with 4 nodes, tetrahedraQuadratic with 10); printed structure (layers: LayerStack slab planes, elemSlabIndex, weld interfaces, tieAlpha); sources (toolpath, sliced package, plain model, brep); results (displacements, element stress, failure mode, failure step, appliedForces arrows); display state (active scalarMode, dead-element view, section plane). Grey nodes are modules: an edge means the module writes or reads that group. SimulationRecord (dashed) captures and restores the whole model. selectDefaultResult opens a finished run on the most useful view.
