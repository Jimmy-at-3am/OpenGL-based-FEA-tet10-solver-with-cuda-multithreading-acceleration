# Test pieces — print guide

Generated by `tools/validation/make_specimens.py` (CadQuery). Everything is in
**millimetres, actual size, already in print orientation** — import and print
without rotating or scaling. `preview.png` shows every part.

- `print/` — what you print (`.stl`), plus the same parts as exact CAD (`.step`)
- `sim/` — simulation copies for `validate.py predict --geometry ...`

## Slicer profile (every part)

| Setting | Value |
|---|---|
| Material | PLA, one spool, dried |
| Nozzle / layer height | 0.4 mm / 0.2 mm |
| Walls | 2 |
| Infill | 100 %, **rectilinear** |
| Internal solid infill pattern | Rectilinear |
| Top and bottom surface pattern | Rectilinear |
| Ironing | Off |
| Supports | Off — except the twist piece (below) |
| Standing parts | Minimum layer time ≥ 8 s, brim 5 mm |

Keep the profile identical for every part, and save each plate's `.gcode.3mf`.
Let parts rest 48 h before testing.

About 45 parts. They fit on a 256 × 256 mm bed in roughly five plates: two of
standing parts (dogbones, bars), one flat plate of dogbones + C-rings + columns,
one of flat bars, and two of twist pieces.

## Features built into the parts

- **Dogbone:** Ø6.4 holes for M6 bolts, 10 mm from each end.
- **Bars:** 1 mm string groove 80 mm from the block face; the flush side (no step
  at the root) goes **down** in the test.
- **Twist:** Ø2 string hole through the pad 100 mm from the shaft axis; a small
  vertical notch on the lever's underside marks the shaft axis — set the prop rod
  there for the propped tests.
- **C-ring:** 0.8 mm flats top and bottom to sit on the anvil and under the frame.
- **Columns:** clamp the first 15 mm of the stem in the vise; Ø3 holes for the
  two water bottles.

## Simulation copies (`sim/`)

The solver loads a part's end face, so these copies end where the string pulls:
the bar stops at the groove centre and the twist pad is cut at the hole centre.
Dogbones and C-ring are unchanged.

## After printing

Measure each part with calipers before testing (3 readings): dogbone gauge width
and thickness, bar width and height, shaft diameter, C-ring width and radial
thickness. Reject parts with visible gaps or warping and note them.
